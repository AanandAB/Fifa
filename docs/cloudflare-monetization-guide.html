2. Phase-by-Phase Setup

Phase 1: Domain & DNS (5 minutes)

  1. Buy a domain from Namecheap, Porkbun, or Cloudflare Registrar (at cost — cheapest)
  2. Sign up at cloudflare.com (free tier)
  3. Add your domain → Cloudflare scans DNS → change nameservers at your registrar to Cloudflare's
  4. DNS → Add record: Type CNAME, Name watch, Target @, Proxy ON (orange cloud)

Phase 2: US Machine — Stream Capture

Option A: Software-Only (Free, no hardware)
Uses streamlink to capture Fox/Telemundo website streams. 
# Install streamlink
pip install streamlink

# Capture Fox stream and convert to HLS
streamlink https://foxsports.com/live best -O | ffmpeg -i pipe:0 \
  -c:v libx264 -preset veryfast -b:v 1500k \
  -c:a aac -b:a 128k \
  -f hls -hls_time 4 -hls_list_size 6 \
  -hls_flags delete_segments \
  stream.m3u8

# Serve HLS files via HTTP
python3 -m http.server 8080

Phase 3: Cloudflare Tunnel Setup (US Machine)

# Step 1: Install cloudflared on Windows
# Download: https://github.com/cloudflare/cloudflared/releases
# Or in PowerShell: winget install Cloudflare.cloudflared

# Step 2: Authenticate with Cloudflare
cloudflared tunnel login
# → Opens browser → pick your domain → authorize

# Step 3: Create a named tunnel
cloudflared tunnel create fifa2026-stream
# → Creates tunnel ID and credentials file at:
#   C:\Users\<user>\.cloudflared\<TUNNEL_ID>.json

# Step 4: Route your subdomain
cloudflared tunnel route dns fifa2026-stream watch.yourdomain.com

# Step 5: Run (test first)
cloudflared tunnel run fifa2026-stream

Create config.yml

Save to: C:\Users\<user>\.cloudflared\config.yml

tunnel: <TUNNEL_ID>
credentials-file: C:\Users\<user>\.cloudflared\<TUNNEL_ID>.json

ingress:
  - hostname: watch.yourdomain.com
    service: http://localhost:8080
  - service: http_status:404

Run as Windows Service (auto-start on boot)

cloudflared service install
# Tunnel survives reboots, runs in background

Phase 4: Update Website Player

The stream player in index.html will be updated to point to your Cloudflare domain:

6. Legal Considerations

⚠️ Important
This setup routes your own personal OTA broadcast — which is legally free over-the-air television in the US — through your own infrastructure. You are not re-broadcasting or pirating. However:
  • Check your local laws regarding re-streaming OTA content
  • This is a private relay of your personal TV signal — similar to a Slingbox
  • Do not publicly market this as "free World Cup streaming" — frame it as a fan stats/info site
  • Consult a lawyer if you plan to scale significantly
